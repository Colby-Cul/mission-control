## LEFT SIDEBAR MENU

The app needs a persistent left-side navigation menu. Here's the current plan:

### Menu Items

- **Home**
  - Main dashboard / landing screen

- **Team**
  - **Org Chart View** — Visual hierarchy of the organization
  - **Agents & Sub-Agents**
    - Job descriptions and names for each agent
    - Current AI model they are using (e.g., Claude Opus 4, Sonnet 4, Haiku 4.5)
    - Cost summary per agent (daily, monthly, yearly)
